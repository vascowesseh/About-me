
# About Me | My Coding Journey

My first HTML capstone project, built as part of my journey toward becoming a self-taught software engineer.

## About the Project

Hi, I'm Vasco Wesseh!

I started my coding journey in January 2025 with the goal of teaching myself software engineering and eventually landing my first software engineering job.

This project is a personal website that introduces who I am, my interests, my career goals, and the technologies I plan to learn.
